# OnePKU 交互约定

- 入口：学习（今日、课程、作业、成绩）、校园（通知、校历）、生活（空闲教室、校园卡）、设置。今日进入课程、生活的快捷入口保留统一导航选中态。浏览器历史 hash 支持后退到页面与课程/作业详情；课程和作业详情替换右侧主区域，通知原文使用独立内置窗口。
- canonical owners：App.tsx 拥有导航与登录调度；components/ui.tsx 拥有基础交互；lib/api.ts 拥有请求与校验；pages 下各页面拥有本地选项。所有页面复用 Resource，禁止复制另一种错误或加载模板。
- 数据：后端 Request 枚举白名单，不暴露 shell、任意 URL 或 session token。每个 query 独立。本地缓存持久化并按账号隔离；认证失败清除敏感内容；账号 session 指纹变化清除前端查询，后端按指纹隔离。短信和扫码操作不自动重试。
- 刷新：启动先恢复持久缓存；普通资源五分钟过期，官方校历二十四小时。作业/通知运行中五分钟刷新；其他资源在过期挂载/窗口聚焦或用户刷新时更新。正常更新时间收在刷新按钮提示中。
- 课表：按用户约定不提供个人课程时间表。官方校历显示完整 PDF。考试仅提取来源明确给出的考试文字，源不可用独立报错。
- 作业：待处理为教学网未发现提交记录，不等价于最终教务认定；可切换全部查看。失败课程明确列出。正文只做文本渲染。
- 文件：已读取附件生成短期不透明 ID，下载到 Downloads/OnePKU/学期/课程；同名同内容复用、更新版本另存，附来源和 SHA-256；100MiB 上限、最多 3 个并行、五分钟超时、取消删除临时文件、防路径穿越和覆盖。
- 回放 MP4：播放和下载共用同账号、同课程、同回放及同播放列表的完整分片；同时请求同一分片时等待同一次下载。下载失败或取消保留完整分片，下载记录提供重试；播放进度同步下载写入的缓存，MP4 下载只补缺片再本地合并。旧播放缓存通过指纹核对后复用，不删除原件；不同视频版本不混用。短暂网络错误最多尝试三次，401/403 不盲目重试；错误区分授权、网络和本地保存。下载进行中不允许清除共享缓存；旧版已经清掉的片段无法恢复。
- 课程文件目录：下载和资料导入共用保存根目录及目录构造函数，格式为「学期/课程名 课程ID」。列表、预览、默认应用打开及回收站操作共用目录查找规则，兼容同一课程 ID 的旧学期/旧名称目录与当前学期的早期纯课程名目录。学期或名称修正不搬移旧文件；通过来源记录兼容新旧附件标识，不按文件名认领附件，不跨课程或当前保存根目录查找。
- 外链：官方站点别名与经校验的 HTTP(S) 正常链接，经系统默认浏览器打开；拒绝含凭证或自定义协议的链接。网页登录与应用凭证分别由学校决定。
- Auth：独立 course / treehole / campuscard / bdkj 会话。树洞短信与课表二次授权分开显示；关闭扫码弹窗停止轮询并删除待登录尝试。
- 无请求成功数据时，局部 skeleton/error/empty，侧栏与别的资源始终可用。键盘 Tab/Enter/Escape 全部可用，短信错误在输入框旁显示。

## Canonical UI Map

| Capability     | Canonical owner                 | Source of truth                  | Allowed variants                                                  | Verification                              |
| -------------- | ------------------------------- | -------------------------------- | ----------------------------------------------------------------- | ----------------------------------------- |
| Select/Listbox | Native select, styled centrally | src/styles/app.css               | Building, day, period, semester                                   | Keyboard and selected-value browser check |
| Date           | Native month input              | src/components/CardStats.tsx     | Month selection for statistics; official PDF is a document viewer | Month switch and independent query tests  |
| Form           | Auth component                  | src/components/Auth.tsx          | QR and SMS, noValidate and inline errors                          | Escape, field validation, focus recovery  |
| Scrollbar      | Global CSS                      | DESIGN.md and src/styles/app.css | Main, modal and table overflow                                    | Desktop and narrow viewport inspection    |

校园卡展示统一由 src/components/CampusCard.tsx 拥有；余额、状态与有效期不写入图片。一般数据更新时间统一进入 Resource 刷新按钮 title；错误与旧数据提醒仍可见。内部阅读行与导航无需外链箭头，使用整行 hover/focus 及明确动词。

课程列表按学期分组，仅最新学期默认展开，未标注学期置后；搜索跨学期并展开命中学期，返回课程列表保留搜索。课程详情默认回放，可切换课程通知、资料和教学网成绩，不再重复提供作业入口；资料归档不更改已下载文件。成绩页仅聚合树洞接口返回的正式成绩、学分与 GPA，按学期筛选，缺失 GPA 用破折号；教学网过程分数保留在课程详情，尚未发布且没有反馈的空总计合并为简短说明。校园卡默认收支明细，消费统计按需加载每日和分类数据，各资源独立刷新和报错。树洞不在 GUI 导航。

## 用户发起的写入

- Submission 是作业上传、预览和状态的唯一组件；使用 rfd 系统选择器，无任意路径入参。预览与选择不上传；最终明确按钮才发出。已有提交记录和教师明确无需交文件时走原站或显示说明。
- 操作记录由共享核心持久化；设置页 WriteOperations 读取，不自动发送。账号会话变化重建页面上下文并清除操作查询。
- HTTP 响应不等于提交结果；回执附件内容匹配后才显示已确认。中断后为待核对；用户可读取学校记录或去原站核对，再结束本地记录。
- 校园卡账户区提供“充值与支付”原站入口。设置中保留社区/选退课/校内门户原站办理，主导航保持简洁。

## v0.5 学习与预约

- 旧版曾提供独立智云课堂目录；当前 GUI 撤下该入口，底层查询保留。课程详情集中资料、过程分数和回放；作业由独立页面拥有。
- 视频可原站播放并在后台下载，完成后归档 MP4。最多三个下载任务，每个视频四路分段获取；退出应用停止任务，重新发起下载时复用完整分片。
- 教学研讨占用表按日期、教学楼和上下午筛选；先检查学校是否开放申请。未开放、资料待补全和登录失败分别显示，不把未知时段当作空闲。
- 体育与图书馆使用无本地命令权限的独立学校窗口。所有预约提交、取消仍由用户在原站进行。

场地预约暂缓发布，页面路由、主导航和北大空间账号入口不对用户展示；保留底层实现，完成真实预约旅程验证后再接回。

## v0.6 回放与原文

- 教学网回放默认应用内播放，按需取分片，同时可缓存整节；缓存进度与实际播放状态分开，失败不清除有效缓存，重新打开恢复观看位置。
- 已有回放清单（即使仅缓存部分分片）直接启动本地播放；远端鉴权和缺片下载在后台按需进行，不阻塞读取完整缓存。打开时不逐片读取整节视频做迁移；补片前核对视频版本，禁止新旧版本混播。续播时播放器与后台下载均从观看位置起步，首次无清单仍需联网获取清单和起播分片。
- 教学网账号通过已登录的用户信息接口确认，保存用户 ID、学号及验证时间；会话指纹仅管理登录生命周期。回放、下载和字幕复用稳定账号身份；回放首次打开时复用已确认属于同账号、同视频指纹的旧会话分片，保留原文件，不合并未确认或其他账号的数据。缓存进度显示一位小数及实际分片数量。
- 完整缓存可离线播，部分缓存只保证已缓存片段；已退出应用不继续下载。MP4 归档与播放共享完整分片，输出的 MP4 文件单独保存在资料目录。
- 通知列表提供索引与已读；公共正文默认内置浏览器直接展示原网页，不再依赖正文抓取。独立原文窗口没有本地 IPC 权限，正常网页登录由用户完成。

- 课程资料以教学网附件为主列表，按已校验来源将下载副本合并到原附件，点击已下载文件直接打开；来源不明或手动添加的文件保留在本机补充，不按同名合并。本机添加使用系统多选文件框，复制归档，更多菜单提供行内确认后移到废纸篓；列表不展示文件系统路径。教学网文件仍由原有下载流程拉取。无截止时间在列表和详情均不显示空占位；教师明确无需交文件时在作业标题下说明。不再提供提醒页或后台通知轮询。

- 通知来源采用单一筛选器，与搜索、只看未读和当前结果计数同行；保留订阅管理与各来源失败提示。设置按账号与登录、字幕、数据与存储、关于与原站入口分组，说明与空操作记录默认折叠，有未确认操作时展开。跨主页面导航回到顶部并聚焦主内容，字幕设置直达仍定位到字幕区域。

- 已提交作业首先展示评分与反馈，原说明/教师附件折叠；未提交作业仍优先展示说明。当前分数、无分数与读取失败分开呈现。历史记录和已交附件通过只读模式获取，查看反馈不创建提交尝试。课程通知无论全局是否订阅，都可在该课内读取；原文直接定位对应课程公告。

## 回放字幕

字幕操作收在播放器的「字幕」入口。生成后台运行并显示阶段与进度；失败或取消保留原字幕，完整生成后自动装载。字幕可单独关闭、导入 SRT/VTT 和调整延迟。全屏使用视频原生字幕；清理视频缓存不删除字幕。模型配置属于本地适配层，不把程序路径、模型日志或教学网凭据放进播放流程。

全屏回放独占原生窗口，底部控制栏覆盖画面、不挤占视频高度。静置约两秒后隐藏控制栏与鼠标，移动鼠标或键盘操作唤回；拖动进度条、操作展开菜单及键盘焦点所在的控件时保持可见。Escape 恢复进入前的窗口状态。
