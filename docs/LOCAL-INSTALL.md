# macOS 本机安装

日常只启动 `~/Applications/OnePKU.app`。`target/` 中的 `.app` 是构建产物，历史 worktree 内的包是旧测试版本，不作为日常入口。

在常用源码目录执行 `./script/build_and_run.sh`（Codex 的 Run 按钮同样调用它）。脚本构建 Tauri、写入 `Contents/Resources/onepku-build.json`、完成本机 ad-hoc 签名与严格校验，然后替换并打开正式路径。无需发布 GitHub Release，也不需要发行签名密钥。

- 只构建：`./script/build_and_run.sh --build-only`
- 安装已经构建并校验的包：`./script/build_and_run.sh --install-only`
- 不保存旧应用备份或重复安装包；成功安装后删除临时构建 `.app`。
- 用户资料、字幕、登录凭据与设置保持在各自现有位置，不随应用替换而删除。

本机整合版为 0.12.3，尚未发布 Release。应用内更新仍读取 GitHub 的已发布 Release；推送源码不会自动更新本机应用。

## 验证边界

基线：132 项前端测试、93 项核心 Rust 测试通过。整合版增加笔记、登录提示与快照迁移回归验证；将课程笔记换回原实现后，新加的三个编辑器测试均失败，恢复修复后通过。

检查包括前端完整测试、类型、格式、设计令牌、培养方案结构，Rust 核心与 vendored course/common 测试，以及 macOS 构建、签名和启动。培养方案检查仍有上游解析警告；结构通过不代表所有培养方案记录内容正确。自动换票的真实过期场景和 Windows/Android 安装不由这些本机结果证明。

回放优先使用课堂实录，教学网保留备用入口。修复了“未连接课堂实录就挡住整个回放页面”和旧版钥匙串凭据被新版忽略的问题；复用旧凭据前核对当前教学网身份，静默换取课堂实录票据，失败后不循环登录。忘记密码同时清理新旧保存位置。凭据与票据均不进入前端或日志。
