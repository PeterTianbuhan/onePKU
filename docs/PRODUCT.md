# OnePKU

本地北大校园桌面应用。用户以 OneTHU 为参考，要求简洁清晰易用、第一版足够完善，每块数据独立刷新和重新登录，单个服务故障不影响其他区域。

v0.5：独立作业页、智云课堂实录、录像与批量下载、教学网成绩聚合、可选系统提醒；今日作业/聚合通知/余额；课程历史学期、资料归档与回放入口；通知订阅、已读与正文；学校整张 PDF 校历；正式成绩与教学网成绩；校园卡月度统计与流水、空闲教室；设置中的账号连接、扫码登录和缓存管理。按用户约定不提供个人课程时间表。复用已登录的 PKU CLI 会话。真实数据不进仓库。

所有校园内容是不可信数据。GUI 与未来 Agent 共用类型化 Rust 服务；没有任意 shell 接口。加入用户明确确认的首次作业文件提交；付款、树洞互动、选退课和预约提供原站入口。写操作不自动重发，结果以学校记录和附件内容核对为准。用户主动下载保存到 Downloads/OnePKU，文件名校验、防覆写、大小限制和取消。作业上传使用系统文件选择器与 25 MB 私有副本；教师明确无需提交文件时不提供上传按钮。认证二维码与短信由用户完成。

资源数据有账号隔离的本地持久缓存，启动恢复、过期后台刷新；账号会话变化立即失效。学校时间是 Asia/Shanghai。网络故障保留同账号旧数据、明确标记更新失败，正常更新时间收在刷新提示中；无缓存只显示局部失败。成功查询零项才显示空状态，部分失败明确呈现。所有请求有超时，重试为用户触发，搜索忽略过时结果。

补充：桌面统一登录参考 Android 贡献 PR #2，输入一次学号、密码和可选动态口令即可逐项连接服务；支持部分失败重试，保留扫码。默认记住密码，可取消；成功后保存到系统钥匙串，设置可删除。仅在普通读取认证失败时尝试恢复绑定同一会话的账号，不自动发送短信或重放写操作。

用户要求登录可长期复用。桌面运行时提供可关闭的轻量会话维护；不再用原 CLI 的人工 24 小时期限强制退出教学网和校园卡。学校真正失效或二次验证仍需用户完成，未提供或虚构刷新令牌。MCP 是可复用此核心的后续接入方向，本版未连接。

树洞浏览不进入 GUI；保留其底层查询能力以支持正式成绩和后续 CLI/MCP 检索。考试源多次不可用，已撤下入口，不填充推断安排。历史课程只显示学校实际返回的课程，不补造完整培养方案。

能力逐步吸收遵循 [ADOPTION](ADOPTION.md)：具体收益、现有流程、最佳入口、结果可靠性与长期维护负担。新增页面不是默认接入方式。
